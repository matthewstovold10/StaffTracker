# StaffTracker

A staff management web app I built during my work experience at Infotel UK.

Built with HTML, CSS, JavaScript, Java (Spring Boot) and MySQL.

## Features

- View all staff with their ID, job, department, manager and status
- Add new staff using a pop-up form
- Search staff by name or ID
- Filter staff by department
- Delete staff with a confirm message

## Database (SQL)

- Three tables: Staff, Managers and Departments
- Tables linked using primary and foreign keys
- Planned with an entity relationship diagram (ERD)
- Staff IDs shown as S001, S002 etc.
